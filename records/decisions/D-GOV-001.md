# Decision: D-GOV-001 — Starter design

- **Date:** 2026-10-04
- **Decision maker:** root coordinator under the user's creation request
- **Status:** effective for this starter; operational adoption still requires owner activation

Use autonomous domain work, one integrator, a separate reviewer, and human-reserved governance. Shared non-sensitive records are readable; writes are scoped. Stronger confidentiality and review-context isolation require runtime enforcement outside Markdown and Git branches.

Alternatives: pure hierarchy simplifies control but concentrates coordination; unrestricted federation risks unresolved interfaces; universal voting cannot certify factual correctness. VSM supplies a function checklist, not a required agent count.

Evidence: [foundations](../../research/foundations.md), [sources](../../research/sources.md). This is a proposed architecture, not an empirically validated deployment. No agent dissent reported during drafting; independent review is pending. Supersedes: none.
