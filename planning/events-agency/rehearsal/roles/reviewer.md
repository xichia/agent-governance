# Independent reviewer contract — rehearsal only

- **Assigned agent / session / model:** coordinator assigns and records a distinct reviewer session and actual model after candidate freeze. The reviewer must not have drafted or integrated the candidate; this document does not assign an identity.
- **Accountable to / substitute:** task owner through the coordinator. No substitute is configured; without an eligible separate reviewer, the run is inconclusive and cannot be closed as reviewed.
- **Mandate:** inspect a fixed integrated candidate against the pinned task criteria, brief/interface, source pack and exact candidate identifier. Check completeness, consistency, sources, arithmetic, time/capacity/resource feasibility, dependencies, version/change acknowledgements, accessibility detail, unsupported claims, open decisions and scope boundaries. Report evidence and edge cases, not preference alone.
- **Inputs / outputs:** receive candidate commit or content hash, criteria, relevant inputs, and validation evidence. Write a new review artifact at `runs/<run-id>/reviews/<candidate-id>.md`; record candidate ID, criteria, checks, evidence, limitations, and verdict: `pass`, `changes_required`, or `inconclusive`.
- **Independence / dependencies:** review starts only after integration has frozen the candidate. Do not edit implementation files, coordinate authors during initial inspection, or approve your own prior work. If content changes, review the new candidate or document a narrow recheck of unchanged evidence and changed areas.
- **Local decisions:** determine whether evidence supports each criterion; identify missing evidence and distinguish a substantive defect from an optional improvement. A pass applies only to the recorded candidate and criteria.
- **Reserved / escalation:** reviewer cannot change criteria, accept owner-reserved risk, grant authority, integrate or mark the task done. Escalate criteria conflict or residual risk to owner through coordinator; preserve disagreement and failed checks.
- **Read / write / tools:** read task, governance, criteria, frozen candidate and necessary source/evidence. Write only the assigned review artifact. Use only the local deterministic checker if assigned; no network or external actions.
- **Proposed ceiling:** 8 minutes / 6,000 generated tokens; one role session; maximum four model-response turns; no session restart/retry. This shares the run's 60-minute total wall-clock, six-session cap and at most two correction rounds. These are proposals only, not enforced grants or authority to spend; the owner must explicitly accept them before dispatch. If token usage is unavailable, use the session/turn/wall-clock bounds and record token telemetry as unavailable. If evidence cannot be assessed within the bounds, return inconclusive.
- **Review / activation:** independent assessment is not human approval, legal clearance, or activation. No live rehearsal is authorized by this contract.
